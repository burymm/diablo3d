# 01. Идея и цели

## Что хотим

- Играть в **Diablo 1: The Hell 4** в **3D**-представлении (вид от третьего лица /
  вращаемая камера / свободный обзор — точный формат ещё обсуждается).
- Хостить 3D-представление в **Garry's Mod**, используя его движок (Source), рендер,
  физику, UI и Lua как «площадку».
- Сделать **прослойку-мост**: TH4 = источник правды (симуляция, логика, данные мира),
  GMod = представление (рендер) + ввод (управление).
- В идеале — **универсальный API**: единый протокол доступа к состоянию Diablo 1, чтобы
  завтра тот же поток данных можно было подать в Unity, Godot, Unreal, веб-вьюер,
  аналитику, ботов и т.д.

## Явные принципы (предложение, обсуждаем)

1. **Один источник правды.** Игровую логику НЕ переносим в GMod. Правила, ИИ, генерация,
   бой, лут — всё живёт в TH4. GMod ничего не «додумывает» (иначе получим две расходящиеся
   реальности).
2. **Разделение слоёв.** Мост не знает о GMod; GMod-аддон не знает о внутренностях TH4.
   Между ними — версионированный протокол.
3. **Данные — не пиксели.** Передаём структурированное состояние мира (сущности, тайлы,
   события), а не картинку. Тогда любой движок рендерит это по-своему.
4. **Совместимость по возможности.** Не ломать игру: TH4 должен оставаться играбельным сам
   по себе; экспорт — побочный, отключаемый слой.

## Что считаем успехом (по уровням)

| Уровень | Результат |
|---|---|
| L0 | Есть стабильный поток состояния мира из TH4, читаемый программой-клиентом. |
| L1 | В GMod видно 3D-сцену, повторяющую уровень Diablo (наблюдение, без управления). |
| L2 | Управление из GMod доходит до TH4 (персонаж реально ходит/атакует). |
| L3 | Полноценный HUD/инвентарь/скиллы в GMod, комфортная игра. |
| L4 | API задокументирован, есть второй потребитель (не GMod), протокол версионирован. |

## Не-цели (пока)

- Полный порт Diablo 1/TH4 на движок Source (нереально по объёму).
- Сетевая многопользовательская игра «через интернет» на базе GMod-сервера (это отдельная,
  гораздо более сложная задача; см. открытые вопросы).
- Поддержка оригинального Diablo 1 / Hellfire / других модов TH — фокус именно на TH4.

## Термины

См. `GLOSSARY.md`. Кратко: **TH4** — игра-источник; **GMod** — движок-представление;
**мост/bridge** — процесс передачи данных; **Fine Map** — сетка 112×112, в которой живёт
игровой мир TH4; **CEL/CL2** — форматы спрайтовых тайлов/анимаций Diablo.
