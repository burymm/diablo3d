# 19. План: «поиграть в Diablo в 3D» (режим шутера)

**Цель (формулировка владельца, 20.10.2026):** играть в Diablo в 3D, причём
интересно «пострелять» — как в Heretic/Hexen, но на **хардкоре** и на
**рандомных уровнях Diablo**.

**Ключевой факт, определивший план:** GMod-сервер **наш** (локальный
listen server / New Game) → серверные скрипты и энтыти доступны.

---

## 1. Что уже бесплатно (делает сама TH4)

| Требование | Как закрывается |
|------------|-----------------|
| Рандомные уровни | TH4 генерирует их при новой игре (`.dun` + seed) — нам просто нужен текущий |
| Hardcore | Режим TH4: смерть = конец. Наш код не должен это обходить |
| ИИ монстров, атаки, лут, магия, опыт | Настоящая TH4 — берём состояние, а не симулируем |
| Звук/анимации | Пока 2D-спрайты оригинала; 3D-ассеты — отдельная задача |

Значит **портировать механику в GMod не нужно**: TH4 остаётся источником
правды, а мы делаем 3D-представление и пульт. Это в 10–20 раз дешевле
полного порта (см. `docs/01-ideya-i-celi.md`, принцип 1).

> Альтернатива «портировать механику» обсуждалась и отклонена: TH4 — C++ под
> DirectX 9, объём (движение, 8 классов монстров, предметы, ~100 эффектов
> магии, скриптовые события) — это отдельный проект на месяцы.

## 2. Архитектура

```
                    shared memory D1BridgeState
   ┌────────────────────────┬───────────────────────────┐
   │  TH4 (th43d.exe)      │  GMod (наш сервер)         │
   │  источник правды      │  sv_d1bridge_win64.dll     │
   │  d1bridge.cpp в TH4   │  читает SHM напрямую       │
   └──────────┬─────────────┴─────────────┬──────────────┘
              │ состояние мира            │ команды
              │ (герой, карта, монстры)   │ (ходьба, атака, каст)
              ▼                           ▼
        сервер: энтыти GMod        герой TH4 реально ходит/бьёт
        (уровень, монстры)         (AI, лут, опыт — настоящие)
```

* **Сервер** читает SHM сам (`sv_d1bridge_win64.dll` — тот же бинарник, что и
  клиентский `gmcl_`, только с серверным именем; установлен ✓).
* **Сервер** двигает игрока в клетку героя TH4 → точное соответствие.
* **Сервер** спавнит энтыти уровня и монстров.
* **Клиент** отправляет команды (ходьба/атака) — канал уже работает.

## 3. Шаги

### Шаг 1. 3D-уровень в перспективе от первого лица — ✅ в работе
* Клиент рисует уровень через IMesh (`mesh.Begin/Quad/End`) в хуке
  `RenderScene`, камера — `cam.Start3D` либо штатная (режимы `player`/`iso`).
* Ограничения API — см. `docs/17-gmod-api-ogranicheniya.md`.

### Шаг 2. Сервер ставит игрока в клетку героя — ⬜
* `bridge/gmod/server/d1server.lua`: читает SHM серверным модулем,
  `ply:SetPos()` в клетку героя (координаты: `X = Col*CELL`, `Y = Row*CELL`).
* Даёт: точное соответствие «герой TH4 = игрок GMod», и WASD можно убрать
  из клиентского хака (двигает TH4, сервер возвращает позицию).

### Шаг 3. Монстры в 3D — ⬜
* Расширить публикацию в TH4 (`vendor/the-hell-4-src/src/d1bridge.cpp`):
  список монстров (тип, `Row/Col`, состояние).
* Карта памяти уже разобрана: `docs/13-karta-pamyati-th4.md`.
* Сервер спавнит энтыти на их местах.

### Шаг 4. Выстрел = атака — ⬜
* ЛКМ → команда атаки в TH4 (`PCMD_ATTACK`) в сторону взгляда.
* Уже есть командный канал (`send_command` в DLL) и рабочая ходьба
  (54–110 мс) — нужен только код атаки + прицеливание по монстру.

### Шаг 5. Отрисовка на серверных энтытях — ⬜ (опционально)
* Уровень как `func_brush`/`prop_dynamic` → штатные свет, тени, коллизии.
* Ограничение: много энтытей (45×45 клеток) — нужен батчинг/сетка.

### Шаг 6. HUD — ⬜
* В этой сборке `HUDPaint` молчит → рисовать через `DrawOverlay`
  (либо перенести HUD на серверные VGUI-панели).

## 4. Известные риски

| Риск | Митигация |
|------|-----------|
| Много энтытей на сервере | батчить (одна энтить на N клеток), либо оставить клиентский IMesh-рендер |
| Шаг 3 требует правок в TH4 → нужна пересборка `th43d.exe` | `bridge/reader/build_th43d.bat`, toolset v145 (не VS2019 BuildTools!) |
| GMod-клиент без `HUDPaint`/`CalcView` | рисовать через `DrawOverlay`, камеру — `cam.Start3D` |
| «Портировать механику» расползается | держать принцип «TH4 = источник правды» |
