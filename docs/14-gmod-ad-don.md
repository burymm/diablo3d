## Что сделано

Клиентский скрипт, читающий снимок моста и выводящий HUD. Кладётся в штатное место
`autorun` и загружается в **любой** карте автоматически — регистрация в меню
«Установленные дополнения» не нужна.

```
D:\SteamLibrary\steamapps\common\GarrysMod\garrysmod\lua\autorun\client\d1bridge.lua
```

Путь данных (тот же, что пишет reader):

```
D:\SteamLibrary\steamapps\common\GarrysMod\garrysmod\data\d1bridge\snapshot.json
```

## Как включить в GMod

1. Запустить Garry's Mod.
2. **Зайти на карту**: «Играть» → «Песочница» → `gm_construct` (или «Найти игру» → «Создать»).
   В **главном меню** панели нет и команд нет — Lua- autorun грузится при старте игрового мира.
3. В игре открыть консоль (`~`) и ввести `d1bridge_status`.

> ⚠️ Важно: команды (`d1bridge_status`, `d1bridge_toggle`) регистрируются **только после
> загрузки карты**. Ввод их в главном меню даёт `Unknown command`.

## Почему не аддон через `addons/`

Первая версия клалась как локальный аддон (`garrysmod/addons/d1bridge/addon.json`).
Надёжнее оказалось штатное `garrysmod/lua/autorun/client/` — оно грузится всегда и не зависит
от того, подхватил ли GMod новую папку аддонов. Дублировать файл в обоих местах нельзя:
HUD отрисуется в два слоя.

## Как работает

- `timer` с интервалом **0.2 с** (5 Гц) читает `file.Read("d1bridge/snapshot.json", "DATA")`
  и парсит `util.JSONToTable`.
- Рисуется панель слева сверху (`hook "HUDPaint"`):
  - **HP / Мана** — полоски; значения в TH4 fixed-point (×64), поэтому делим на 64
    (`CurLife=3200` → 50 HP). При HP ≤ 25 % полоска меняет цвет.
  - Уровень, золото, опыт, класс, имя героя.
  - Подземелье, координаты `Row/Col`, направление (0..7 → «вверх…вниз-влево»), `base`.
- **Индикатор связи** в шапке панели:
  - `OK pid=… возраст … c` — снимок свежий;
  - `УСТАРЕЛО (N c) — TH4 выключена или reader остановлен` — файл не обновляется
    дольше **3 с** (проверяется по полю `ts`);
  - `НЕТ ДАННЫХ (файл не найден)` — reader не запускался ни разу;
  - `reader: Player не найден (ok=false)` — снимок есть, но `player` отсутствует
    (например, последней командой была `info` вместо `watch`).

## Команды

| Команда | Действие |
|---------|----------|
| `d1bridge_toggle` | показать/скрыть панель |
| `d1bridge_status` | вывести в чат путь, статус связи и текущие значения героя |

## Проверка «соединится ли»

1. Запустить **TH4**, зайти в **игру** (не в главное меню).
2. Открыть PowerShell **от имени администратора** (процесс TH4 32-битный/WOW64):
   ```
   cd E:\games\diablo-1-source\bridge\reader
   python d1reader.py info          # процесс и модуль найдены?
   python d1reader.py watch -v      # живой поток, печатает Lvl/HP/Gold/Row/Col
   ```
   `watch` печатает кадр каждые 0.2 с — значит чтение памяти работает.
3. Запустить GMod, зайти на карту. Панель слева сверху должна показать
   `OK pid=… возраст 0.1 c` и **живые** HP/ману/координаты.
4. Ходить в Diablo и смотреть, что `Row/Col` и HP меняются в GMod.

Если панель показывает `УСТАРЕЛО` — TH4 закрыта или остановлен `watch`.
Если `НЕТ ДАННЫХ` — reader ещё ни разу не писал файл по этому пути
(проверить `--out` у `watch`).

## Обратный канал (добавлено 16.10.2026)

| Команда | Действие |
|---|---|
| `d1_step right` | шаг на клетку: `up up-right right down-right down down-left left up-left`, синонимы `w a s d q e z c` |
| `d1_step w 3` | шаг на 3 клетки |
| `d1_goto 50 87` | идти в клетку `Row`/`Col` |
| `d1_mode post` / `d1_mode cursor` | способ ввода в TH4 (по умолчанию `post` = без фокуса) |
| `d1_click [x y]` | клик в точку окна (0..1), низкий уровень |
| `d1_ping` | проверка, что reader видит команды |
| `d1_ack` | ответ reader'а на последнюю команду |

По умолчанию ввод уходит через «курсор + PostMessage»: **окно TH4 остаётся
развёрнутым, но не в фокусе** (его можно перекрыть GMod или убрать на второй
монитор), фокус не перехватывается, системный курсор возвращается на место.
**Сворачивать TH4 нельзя** — свёрнутое окно ввод не обрабатывает.
Подробности — `15-obratnyy-kanal.md`.

## Ограничения (осознанно, для MVP)

- Показывается только **герой**; монстры, предметы и карта мира не читаются
  (см. `13-karta-pamyati-th4.md`, раздел «Что ещё НЕ найдено»).
- `xOfs/yOfs/xVel/yVel` в карте есть, но значения неподтверждены (мусор),
  поэтому интерполяции движения нет — только дискретные `Row/Col`.
- Обратный канал управляет героем дискретно (шаг на N клеток); скорость и
  длина шага определяются самой игрой.
